Security

Version 1.0 · 03 September 2026 · Earlier versions stay available at /security/v1.html

How the service is protected, in enough detail for a technical reviewer.

Accounts

  • Passwords stored as Argon2 hashes. We cannot recover them, only reset them.
  • Sign-in and password reset are rate limited.
  • Session cookies are HTTP-only, secure and same-site.

Lessons

  • Six-character room codes from an alphabet with no O and 0 or I and 1, so they cannot be misread aloud. Guessing is rate limited.
  • A waiting room is on by default; the teacher admits each student.
  • Session state lives in memory and is destroyed when the lesson ends.
  • What a student is allowed to do is checked on the server for every action, not only hidden in the interface.

Files

  • Images and PDFs only, size limited, held for the teacher to approve.
  • Location and camera data stripped from every uploaded image, on the server.
  • Download links are signed and short lived.
  • Storage deletes submitted work after seven days automatically.

The page itself

  • TLS everywhere.
  • A content security policy that allows no third-party origin.
  • Every library is served by us. Nothing is fetched from a content network, so no other company sees your visitors.
  • A check in the build fails if an external address appears anywhere.
